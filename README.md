# RTSyn Defaults

Shared default values for RTSyn modules.

This package is header-only and exists so process-level defaults are not copied
between modules.

## Headers

- `rtsyn/api/defaults.h`
- `rtsyn/engine/defaults.h`
- `rtsyn/runtime/defaults.h`
- `rtsyn/spsc/defaults.h`

## Usage

```c
#include <rtsyn/spsc/defaults.h>
```

```cpp
#include <rtsyn/api/defaults.h>
```
